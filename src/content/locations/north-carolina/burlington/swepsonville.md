## Sequencing the work against the calendar

Once conflicts clear, the engagement is mapped against the case
schedule: records requested early enough to be fought for if necessary,
the evaluee's interview and testing placed so results are fresh at
disclosure, and drafting time protected so the written opinion is
complete rather than provisional when it is served. Rebuttal
assignments run on the same logic in reverse, working from the opposing
report's service date toward the deadline for response. Counsel see the
plan before the work begins, which makes the expert file easier to
defend at deposition.
